## [1.0.0] - 2025-01-01

### Added
- Initial release of 6-Digit Calculator
- Addition operation (+)
- Subtraction operation (-)
- 6-digit input limit with validation
- Overflow detection for results exceeding 6 digits
- Real-time input validation
- Responsive design for desktop and mobile
- Accessible UI with ARIA attributes
- Comprehensive documentation (README.md)
- Contribution guidelines and templates
- MIT License

### Technical
- Pure HTML, CSS, and vanilla JavaScript implementation
- No external dependencies
- Client-side only (no backend required)
- Compatible with Chrome 90+, Firefox 88+, Edge 90+
